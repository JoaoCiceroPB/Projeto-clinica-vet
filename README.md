# 🐾 Landing Page - Clínica Veterinária (projeto de portfólio)

Landing page responsiva para uma clínica veterinária, com apresentação dos serviços, da equipe e contato pelo WhatsApp.

> ⚠️ **Projeto de portfólio.** Desenvolvido como proposta para uma clínica veterinária, que não chegou a ser contratada. Todos os dados exibidos (nome, telefone, equipe) são **fictícios**.

## 💻 Demonstração

Acesse o projeto online: [Visualizar o site](https://joaociceropb.github.io/Projeto-clinica-vet/)

## 🚀 Tecnologias Utilizadas

- **HTML5:** estrutura das seções da página.
- **CSS3:** estilização e layout.
- **Font Awesome:** ícones.
- **Google Fonts (Poppins):** tipografia.
- **Git, GitHub e GitHub Pages:** controle de versão e publicação.

## ✨ Funcionalidades

- Menu de navegação por seções (Início, Serviços, Equipe e Contato).
- Seção de serviços organizada em cards.
- Seção de equipe.
- Botões de WhatsApp no cabeçalho, na área principal e flutuante.

## 📚 Origem do projeto

Projeto criado por mim como proposta comercial para uma clínica veterinária. O negócio não foi fechado, e os dados reais foram substituídos por dados fictícios para uso no portfólio.

## 🧠 O que aprendi

- Montar uma landing page com seções (destaque, serviços, equipe e rodapé).
- Usar Font Awesome e Google Fonts.
- Publicar um site com GitHub Pages.
